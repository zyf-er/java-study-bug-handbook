# Java 学习与 Bug 排查手册

记录 Java 学习过程中遇到的常见问题、错误原因、排查过程和解决方案。

## 📚 知识库目录

- Java基础：Java 基础语法及常见异常
- SpringBoot：项目启动、Bean 注入、端口占用等问题
- MySQL：数据库连接及 SQL 执行问题
- MyBatis-Plus：Mapper 映射及 CRUD 问题
- Maven：依赖下载及项目构建问题
- Git-GitHub：版本控制及代码推送问题

## 🎯 项目目标

1. 积累真实 Java 项目开发经验。
2. 建立个人 Bug 排查知识库。
3. 记录常见错误及解决方案。
4. 将技术学习过程整理为 CSDN 博客。

## 📝 记录规范

每个 Bug 尽量包含：

1. 错误现象
2. 错误原因
3. 排查过程
4. 解决方案
5. 相关代码及截图
